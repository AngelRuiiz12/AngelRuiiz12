## 🚀 Proyectos destacados

### 💸 [expense-tracker-api](https://github.com/AngelRuiiz12/expense-tracker-api)
API REST de control de gastos personales. Es el proyecto con el que más he profundizado en seguridad y calidad de backend.

- **Stack:** Python 3.13, FastAPI, PostgreSQL 17, SQLAlchemy 2.0, Alembic, Docker.
- Autenticación **JWT** con *refresh tokens* rotatorios y detección de reutilización (si un token ya usado reaparece, se revocan las sesiones del usuario).
- Contraseñas con **Argon2id**, importes en `NUMERIC(10,2)` para evitar errores de redondeo y *rate limiting* en el login.
- Aislamiento de datos por usuario, filtros, paginación y resúmenes por categoría.
- **45 tests de integración** contra PostgreSQL real y pipeline de **CI con GitHub Actions**.

### ✅ [task-manager-api](https://github.com/AngelRuiiz12/task-manager-api) + [task-manager-frontend](https://github.com/AngelRuiiz12/task-manager-frontend)
Aplicación full stack para gestionar tareas, proyectos y etiquetas.

- **Backend:** Node.js, Express 5, Prisma, JWT + bcrypt, validación con Zod, arquitectura por capas (rutas → controladores → servicios), Helmet y *rate limiting*, documentación con **Swagger/OpenAPI** y **38 tests** (Vitest + Supertest) con CI.
- **Frontend:** React 19, Vite, React Router, Tailwind CSS, rutas protegidas, filtrado por proyectos, dashboard con estadísticas y diseño responsive.

### 📝 [todo-app](https://github.com/AngelRuiiz12/todo-app)
App de tareas full stack con **React** y **FastAPI** (SQLAlchemy 2.0 + Pydantic), con CSS propio sin librerías de estilos, modo oscuro y edición en línea.

### 🎭 [punto-de-partida-escuela-teatro](https://github.com/AngelRuiiz12/punto-de-partida-escuela-teatro)
Aplicación para la gestión de alumnado y mensualidades de una escuela de teatro, desarrollada en equipo durante las prácticas del ciclo DAW.

- **Stack:** Laravel (API REST) + React, PostgreSQL/Supabase y Docker.
